#### Histoire : Les adventure playgrounds

**Origine** : Danemark, années 1940 (architecte paysagiste Carl Theodor Sørensen)

**Constat** : Les enfants préfèrent jouer dans les chantiers (matériaux variés, possibilités infinies) plutôt que dans les aires de jeu standardisées.

**Idée** : Créer des espaces où les enfants peuvent construire, démolir, transformer.

**Principe** :

- Matériaux bruts disponibles (bois, clous, cordes)
- Outils accessibles (marteaux, scies - avec accompagnement adulte)
- Pas de structure imposée (les enfants construisent leurs cabanes, leurs jeux)
- Évolutif (ce qui est construit aujourd'hui peut être transformé demain)

**Diffusion** : Angleterre (1960-70), Allemagne, Japon...
